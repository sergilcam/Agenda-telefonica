# Agenda Telefónica

## Objetivo
Crear una aplicación de consola en Python para gestionar contactos.

## Funcionalidades de la versión 2
- Crear el menú
- Añadir contactos.
- Buscar contactos por nombre.
- Buscar contactos por numero
- Eliminar contactos.
- Mostrar todos los contactos ordenados A-Z o Z-A.
- Guardar y cargar contactos desde contactos.xlsx (hoja Contactos, columnas nombre | telefono).

## Instalación
```bash
pip install -r requeriments.txt
```

## Restricciones didácticas
- Programación estructurada.
- Funciones pequeñas y nombres descriptivos.
- Sin clases en la versión inicial.
- Código comprensible para alumnado de 2.º de Bachillerato.

## Estructura
- `src/`: código del programa.
- `tests/`: pruebas automáticas.
- `data/`: datos de ejecución.
- `docs/`: documentación adicional.

## Ejecución
```bash
python -m src.agenda 
```
